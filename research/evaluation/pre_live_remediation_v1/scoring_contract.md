## Inputs, canonicalization and validity

Authoritative target: exact `target_category` joined from frozen registry by unique sample_id; duplicate/missing/extra IDs or mismatching hashes abort evaluation setup. Nine labels fixed: sampah, jalan_rusak, banjir, listrik, air_bersih, keamanan, kesehatan, pendidikan, lainnya. Targets never canonicalized/reassigned from predictions.

Preserve raw content, literal fields and parse mode. `raw_exact_category` requires a string exactly in the nine-label set. Missing/null/empty-after-trim => `__missing__`; non-string/unrecognized nonempty => `__invalid__`. Explicit raw JSON null is missing, not string "null". Main raw diagnostic is **exact**; supplemental `raw_canonical_category` uses string `.trim().toLowerCase()` only, no aliases, hyphen/space substitution, Unicode confusable repair, stemming or coercion. E.g. ` Jalan_Rusak ` becomes jalan_rusak only in canonical diagnostic; `jalan rusak` remains invalid. `final_category` is actual production normalized output, not overwritten by audit code. No JSON/parseable category => raw missing; all never-attempted rows get `__no_prediction__` for every metric view, not others. Supplemental extraction uses the production regex block selection but recorded distinctly; never imply it was JSON-pure.

Define separately:
- HTTP success: actual HTTP2xx, not a synthesized status; no headers received→null. Service success: returned status success; not equivalent to strict validity/correctness.
- `json_pure`: entire trimmed raw content JSON.parse succeeds to non-null object **not array**. Markdown/prose plus JSON fails this flag.
- `schema_valid`: parsed direct or recovered object has all seven required own fields, literal category in nine labels, secondaryCategories array of known string labels with no repeats or primary category, suggestedDepartment exact one of DLH/PUPR/DISHUB/SATPOLPP/DINKES/DISDIK/KELURAHAN, suggestedPriority exact rendah/normal/tinggi/darurat, reason nonempty trimmed string <=500 chars, confidence integer0–100, needsHumanReview boolean. Extra fields recorded but do not invalidate; no type coercion or normalization for validity.
- **strict_valid = json_pure AND schema_valid AND HTTP2xx AND complete untruncated content.** Recovered JSON may be schema_valid but never strict_valid. Non-JSON provider envelope, missing choices/content, whitespace-only, arrays, malformed or truncated bodies fail strict validity. Class labels can be extractable/correct while strict_valid=false, and vice versa.

## Scoring and denominators

Let P=270 planned frozen rows, A=unique rows for which classifier evaluation invocation started (includes pretransport local rejection), D=transport POST dispatch_started rows (<=270), H=rows with observed HTTP response (<=D). Also track R=reserved slots including uncertain; R cap270. No duplicates/retries0. Never describe A or R as accepted provider requests. Uncertain rows remain no raw prediction unless captured; preserve any production result actually available.

- Category accuracy (raw exact, supplemental canonical and production final separately): matching target /P. Report attempted-only /A and conditional service success /S only as secondary. All unattempted, missing, invalid or no result count wrong for category; never replace sentinel with target. At target lainnya, actual production manual fallback lainnya counts correct **final system** but raw fails and technical failure remains; report this potentially misleading match explicitly.
- Confusion matrix: nine target rows, nine labels plus `__invalid__`, `__missing__`, `__no_prediction__` columns for each view. For class c, TP=M[c,c], FN=sum row excluding TP (includes sentinels), FP=sum other target rows in c column. Precision=TP/(TP+FP), recall=TP/(TP+FN), F1=2TP/(2TP+FP+FN). Set zero denominator class metrics0 and report support; macro P/R/F1 arithmetic mean over **all9** classes. Accuracy denominator P independent of predicted support. Baseline evaluated on same P and targets, identity-checked stored predictions; no changes to frozen baseline. Schema/API-validity for baseline N/A, not100%.
- Strict valid rate=count strict_valid/A; pure JSON rate=count json_pure among observed bodies/A; service failure rate=count invocations ending non-success/no committed result/A. Also report transport HTTP error rate=count observed non2xx/D, timeout rate=timeouts/D, network rate=network errors/D; early local reject count/A separately. If denominator0 => null with count0 and reason, not0% or100%. Distinguish no model output, invalid schema despite service success, HTTP failure and unattempted. Invalid-output-on-HTTP2xx rate=count strict-invalid completed2xx/number completed2xx, plus invalid output count/A. Coverage A/P and D/P reported.
- Fallback full-service/manual, category replacement, department replacement/name-resolution, priority replacement/default, confidence imputation/clamp, secondary filtering/dedup, reason default/truncate tracked individually; flag missing priority/confidence even if defaults match expected. Case/trim canonicalization is transformation, not hallucination replacement. Record raw absence vs invalid vs clamp. A wrong but allowed department is **not fallback**. Count per flag/A; any-fallback union/A, not sum of overlapping events.
- Latency: monotonic invocation→body parsed+production normalization, including failed attempts; report all A and dispatched-only D and successful-only S separately with N and component timings. Local rejects are identifiable, not disguised as network latency. Sort durations x; quantile at h=(n-1)p with linear interpolation between floor/ceil h; median p=.5,p95=.95. n0→null,n1→x. Active-run deadline waits not per-request latency. Baseline local timing is not equivalent to remote LLM network time.

## Scope of remaining outcomes

Department: primary category-derived mapping reference in registry only; raw exact and trim+uppercase supplemental vs normalized saran reported separately. Missing/invalid fail against reference on P; simulated mapping routing named as such (no DB). No substantive agency-jurisdiction accuracy claim. Priority/secondary descriptively retained; no accuracy because no independently specified targets/rubric for them in this dataset.

Confidence/review: descriptive distributions and disagreement against scenario target, not calibration or real human-review effectiveness. Separate raw genuine integer confidence from imputed/clamped system values; do not treat Boolean("false") as raw false. Count reviewed/not-reviewed/unknown, category error proportions per stratum with N; identify high-confidence>=80 wrong and low-confidence<60 correct against synthetic targets only. Department mismatches reported separately, never assumed captured by category review flag.

55 family clusters: row metrics above are primary descriptive results on designed conditions, not independent-event estimates. Supplemental family macro accuracy = mean over55 families of within-family correct_fraction; family-macro metric is named separately, not class macro F1. Report paired LLM vs baseline on identical IDs, plus paired within-family differences. No p-value/population CI claim or bootstrap until resampling algorithm/seed/N is separately preregistered. No tuning/exclusion based on comparisons.
